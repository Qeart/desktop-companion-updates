Aurum Meter 0.2

New WPF frontend, dark/gold appearance, DPS/HEAL selector, healing display,
per-skill healing summaries and modified healing aggregation developed locally.
Floating menu and integrated Hidden Cube compass developed locally. The compass reuses
the existing tested local CubeArrow camera-sector/navigation implementation and the
shared Aurum position decoder; no Kisk executable or code is bundled.
Ctrl item-advice UI, tooltip parser and inventory-comparison/class/slot selection developed locally. Short factual
stat/skill recommendations are attributed in ITEM-ADVISOR.md and data/gear-advice.json.
Automatic Arcana-screen advice is developed locally; factual sources and card-specific
skill recommendations are attributed in ARCANA-ADVISOR.md and data/arcana-advice.json.
Installer, update UI, channel configuration and data migration are developed locally,
using Velopack 1.2.161 (MIT). Copyright Velopack Ltd and contributors; see
licenses/Velopack-MIT.txt and https://github.com/velopack/velopack.

PktMon backend and raw Ethernet/IP/TCP reader were added locally.
Local-player recovery through validated own-stat updates (4A 36) was developed
locally. The record layout/local scope were cross-checked against
https://github.com/taengu/A2Tools-DPS-Meter, commit
a9c18e035f7258f91d9f63e86b76ba532f203387 (GPL-3.0), capture/abnormal.rs,
which credits Seralth's Daevalog (GPL-3.0). See IDENTITY-RECOVERY.md.
ABI documentation:
https://learn.microsoft.com/en-us/windows/win32/pktmon/pktmon-reference
https://learn.microsoft.com/en-us/windows/win32/pktmon/packetmonitor/nf-packetmonitor-packetmonitorcreaterealtimestream
API name/string constants were cross-checked with the interface header at:
https://github.com/emmachase/pktmon/blob/master/pktmon.h
No source from that implementation is bundled; Windows supplies Pktmonapi.dll.

Npcap is installed separately and is not redistributed here.

Black Cloud Market tab packet layout was cross-checked against

and WinRT runtime retain their upstream licences. No Kisk program code is bundled.

0396123a6e38bbc5c09df0c8c44755ddbe68cc79 (GPL-3.0).

Map artwork and underlying game data belong to NCSOFT; original data compilers
retain their copyright. See also data/NOTICE.md.
Map registration uses OpenCvSharp4 / OpenCV 4.13.0, Apache-2.0:
https://github.com/shimat/opencvsharp and https://opencv.org/license/.
The local map feature uses image matching, not OCR or game-process memory access.

https://github.com/amerkoleci/Vortice.Windows, copyright Amer Koleci and contributors.

The default Aurum map now renders its own terrain image and world markers together.
Legacy registration/capture remains in the source but is not used by the owned map.

A2Tools-Plugins pet-souls/manifest.json and nearby.js (GPL-3.0).
